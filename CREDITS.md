# Credits

Ink Rooms was built by Adam Holter with OpenAI Astra.

The character and likeness are reserved assets, excluded from the MIT source-code license. See [asset rights](ASSET-RIGHTS.md).

The character began with Adam's profile image, a manually authored SVG recreation, generated visual references, and a rigged Blender model. The browser model includes Idle and Run animation clips. The environment, crates, machines, robots, and turntables are modeled in TypeScript.

Footstep and crate sound samples were generated with ElevenLabs. Other game cues are authored tones. The instrumental was generated with MiniMax and prepared for the game. No voiceover is used.

Three.js, Vite, TypeScript, and their dependencies retain their respective licenses. The GitHub mark identifies the source repository and belongs to GitHub.

Public Sokoban collections are used only for optional comparison checks, not as bundled levels. Collection authors and source URLs are recorded in `scripts/audit-data/sources.json`.
